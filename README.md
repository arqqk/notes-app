# 📝 Приложение "Мои заметки"

Веб-приложение для iPhone с функциями заметок, календаря и редактируемой таблицы. Работает оффлайн, поддерживает установку на домашний экран.

## ✨ Возможности

- **Заметки** с тремя статусами: ⏳ Ожидает, 🔄 В процессе, ✅ Выполнено
- **Календарь** с привязкой заметок к датам
- **Редактируемая таблица** с добавлением/удалением строк и колонок
- **Шеринг заметок** через встроенный Web Share API
- **Экспорт таблицы** в CSV формат
- **Оффлайн-режим** через Service Worker
- **PWA** — установка на домашний экран iPhone
- **Тёмная/светлая тема** — автоматически в зависимости от системы
- **Свайп-навигация** между вкладками
- **Клавиатурные сокращения**
